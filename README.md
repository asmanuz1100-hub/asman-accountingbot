# ASMAN Accounting Bot

Telegram учун ASMAN бухгалтерия ботининг биринчи ишлайдиган версияси.

## Биринчи версия
- Хом ашё омбори ва қолдиғи
- Хом ашё кирими
- Ҳамкорлар
- Шартномалар ва шартнома қолдиғи
- Қисқа ҳисобот
- SQLite база

## Render
Build command:
`pip install -r requirements.txt`

Start command:
`python bot.py`

Environment variable:
`BOT_TOKEN` = BotFather берган Telegram токени.

**BOT_TOKEN'ни GitHub кодига ёзманг.**
